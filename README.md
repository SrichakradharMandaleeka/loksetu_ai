# LOKSETU AI

**Transforming Citizen Voices into Smarter Constituency Development**

LOKSETU AI is an AI-powered constituency intelligence platform that helps citizens report local issues and helps MPs or government officials turn those issues into ranked, actionable development plans.

Instead of being just a complaint portal, the platform uses AI to analyze citizen feedback, detect urgency, remove duplicates, suggest departments, and recommend practical development works.

## Problem Statement

**AI for Constituency Development Planning – Turning Citizen Voices into Ranked, Actionable Works**

Government representatives receive complaints and suggestions from many channels, making it difficult to prioritize the most important issues. LOKSETU AI solves this by converting scattered citizen voices into organized insights for better decision-making.

## Features

- Citizen issue reporting
- Voice complaint support
- Image upload
- AI complaint analysis
- Priority scoring
- Duplicate detection
- Development recommendations
- Interactive constituency dashboard
- Heatmap visualization
- AI assistant for governance queries
- Analytics and reports

## Tech Stack

- **Frontend:** React, TypeScript, Vite
- **UI:** Tailwind CSS
- **Backend:** Firebase Authentication, Firestore, Storage, Hosting
- **AI:** Google Gemini / Google AI Studio
- **Visualization:** Charts and maps

## Project Flow

1. Citizen submits an issue
2. Gemini AI analyzes the issue
3. The issue is categorized and prioritized
4. MP views ranked issues on the dashboard
5. Development work is planned
6. Citizens track progress and verify completion
